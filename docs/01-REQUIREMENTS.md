# 개인 AI Native 코딩 환경 — 요구사항 (초안 v0.1, 2026-11-04)

상태 표기: **확정** 사용자가 직접 정함 / 제안 근거 있는 제안(승인 필요) / 미정 결정 필요. (2026-11-04 기준 FR1~FR14 전부 확정, 모델 호출 로그 항목만 ④에서 후속)
근거 자료: 사용자 설계안 "AI Native 개발 워크플로우 설계안", `lab/code/verify-harness/RESULTS.md` 측정.

## 1. 목표
구독 모델(Claude, Codex)이 구현과 도구 호출을 하고, 결과가 "정말 됐는지"는 모델이 아닌 **결정적 게이트**가 증거로 판정하는 1인용 개발 환경. 로컬 LLM(Mac mini, gpu-server)은 검증 보조로 쓴다.

## 2. 범위와 전제
- [확정] 대상: 기존 저장소의 기능·수정 + 새 프로젝트 시작, 둘 다.
- [확정] 작업 방식: 대화형(같이 진행)과 무인(맡겨 두고 결과 확인) 둘 다.
- [확정] 구현·도구 호출은 구독 모델(Claude, Codex). 로컬 모델이 구독 모델을 대체할 필요 없음.
- [확정] 자격증명만 로컬 전용. 나머지 코드·문서는 구독 모델로 보내도 됨.
- [확정] 사람 승인 필수: 파일·데이터 삭제, 운영 서버·계정 권한 변경.
- [확정, 기존 전역 규칙] 발행·배포·메시지 전송·구매는 사용자 권한 범위를 넘지 않는다(CLAUDE.md). 이번 질문에서 선택하지 않았으나 기존 규칙이 우선 → OQ2에서 확인.
- 사용자 1인, 장비: MacBook(작업), Mac mini(상시), gpu-server(온디맨드), minipc02.

## 4. 비기능 요구사항
- 전력·비용(측정): 상시 서비스는 Mac mini(부하 평균 약 14W, 대기 약 0.2W 패키지), gpu-server는 배치·실험 때만 켠다. 전기료 금액은 추정.
- 격리: Mac mini의 기존 서비스(OpenClaw, Hermes, AI Trading 등)에 영향이 없어야 한다(모델 상주 메모리 합계 여유 유지).
- 재현성: 로컬 모델은 이미지 digest·모델 버전을 고정한다.
- 접근: Tailscale 내부 전용 엔드포인트.
- 복구: Mac mini 재부팅 후 상시 서비스가 자동 복귀한다.
- 개인 정보·자격증명은 보고서와 로그에 남기지 않는다.

## 5. 이미 측정으로 알게 된 제약 (설계에 반영)
- 로컬 4B/9B는 분류 정확도 88~92%이나 증거 불충분(일부만 실행, 오래된 증거)을 `ok`로 통과시킨다 → 이 판정은 규칙이 맡는다.
- 구독 모델은 이 toy에서 만점, T4(테스트 제안)도 만점.
- Mac mini 35B-A3B는 T4가 안정적(6/6/6), 호출당 약 1.5~3.6초.
- GPU 동시 처리 시 에너지가 가장 적고, 순차·간헐 요청은 Mac mini가 유리.
